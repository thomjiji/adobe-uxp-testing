# Adobe UXP Plugin Development for Premiere Pro

Adobe UXP plugins for Premiere Pro.

## Project Structure

```
src/          # Plugin source code
prproj/     # Premiere Pro project files
media/        # Test media files
```

## Quick Start

1. Open UXP Developer Tools (UDT)
2. Add plugin: select `src/test-1/manifest.json`
3. Click ••• → Load
4. Plugin appears in Premiere Pro

## Reload Plugin

In UDT: click ••• → Reload
